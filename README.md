# 🌌 ดาวดึงส์ (DaoDueng) • 360° Stargazing Web App

**ดาวดึงส์ (DaoDueng)** คือเว็บแอปพลิเคชันดูดาวและท้องฟ้าจำลอง 3 มิติแบบ 360 องศา ออกแบบให้ใช้งานง่าย สวยงาม อิงหลักการคำนวณทางดาราศาสตร์จริง พร้อมระบบสำรวจพื้นผิวดาวเสมือนจริง และเสียงพากย์นิทานดวงดาวภาษาไทย

---

## ✨ ฟีเจอร์เด่น (Key Features)

### 1. 🔭 ท้องฟ้าจำลอง 360° สมจริง (Interactive 3D Planetarium)
- แสดงตำแหน่งดาวฤกษ์ ดาวเคราะห์ และดวงอาทิตย์/ดวงจันทร์ ตามเวลาและพิกัดละติจูด/ลองจิจูดจริง (Local Sidereal Time, Alt/Az)
- รองรับการหมุนดูรอบทิศทางทั้งบนคอมพิวเตอร์ (เมาส์/ทัชแพด) และบนมือถือ (เซนเซอร์ Gyroscope / Compass)
- เส้นเชื่อมโยงกลุ่มดาว 88 กลุ่มดาว พร้อมชื่อภาษาไทยและชื่อสากล

### 2. 🪐 สำรวจพื้นผิวดาวแบบ 3 มิติ (Photorealistic 3D Surface Engine)
- **คลิกซูมขยายเพื่อมองเห็นพื้นผิว 3D**:
  - **ดาวเสาร์ (Saturn)**: วงแหวน 3D อนุภาค Raytraced พร้อมเงาตกกระทบสมจริง และดวงจันทร์บริวาร Titan & Enceladus
  - **ดาวพฤหัสบดี (Jupiter)**: แถบเมฆหมุนวน จุดแดงใหญ่ (Great Red Spot) และดวงจันทร์กาลิเลโอ 4 ดวง (Io, Europa, Ganymede, Callisto)
  - **ดวงจันทร์ (Moon)**: แผนที่ภูมิศาสตร์ดวงจันทร์จริง (Lunar Maria: ทะเลแห่งความเงียบสงบ, หลุม Tycho, Copernicus)
  - **ดาวฤกษ์ตามชั้นสเปกตรัม (Spectral Classification)**: คำนวณอุณหภูมิ สี และการไหลเวียนของพลาสมา (Photosphere Granulation) เสมือนจริงตามสเปกตรัม O, B, A, F, G, K, M

### 3. 📖 นิทานดวงดาวและตำนานท้องฟ้า (Star Folklore & Mythology)
- รวบรวมตำนานทั้ง **นิทานดวงดาวพื้นบ้านไทย** (เช่น ดาวจระเข้, ดาวลูกไก่, ดาวเต่า-ดาวไถ) และ **ตำนานเทพปกรณัมสากล** (กรีก-โรมัน, อาหรับ)
- ข้อมูลเชิงลึกของดวงดาวแต่ละดวง อุณหภูมิ ระยะทางปีแสง และความสำคัญทางวิทยาศาสตร์

### 4. 🎙️ ระบบเสียงเล่านิทานภาษาไทย ไหลลื่นน่าฟัง (Thai Neural Storytelling Narrator)
- เสียงพากย์ภาษาไทยนุ่มนวล เป็นธรรมชาติ ไม่สะดุด
- ตัดคำอ่านวงเล็บภาษาอังกฤษและสัญลักษณ์ เพื่อให้การออกเสียงภาษาไทยลื่นไหลต่อเนื่อง
- มาพร้อมเสียงดนตรีบรรยากาศท้องฟ้าจำลอง (Celestial Ambient Soundscape) คลอเบาๆ ช่วยสร้างสมาธิและความเพลิดเพลิน

## 🚀 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: เปิดใช้งานได้ทันที (Standalone)
ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดบนเบราว์เซอร์ได้ทันที (รองรับ Google Chrome, Edge, Safari, Firefox)

### วิธีที่ 2: รันผ่าน Local Node.js Server (เพื่อเสียง Neural TTS คุณภาพสูงสุด)
1. เปิด Terminal ในโฟลเดอร์โปรเจกต์
2. รันคำสั่ง:
   ```bash
   node server.js
   ```
3. เปิดเบราว์เซอร์ไปที่:
   ```
   http://localhost:8080
   ```

## 🛠️ โครงสร้างไฟล์ (File Structure)

- `index.html`: โครงสร้างหน้าเว็บและ UI ท้องฟ้าจำลอง
- `styles.css`: การออกแบบ UI สไตล์กล้องดูดาว ดาร์กโหมดนีออน
- `app.js`: ระบบควบคุมมุมกล้อง, UI, การโต้ตอบ และระบบเสียงเล่านิทาน
- `astronomy.js`: อัลกอริทึมคำนวณตำแหน่งดาราศาสตร์และดาวฤกษ์
- `surface.js`: WebGL 3D Raymarching Engine จำลองพื้นผิวดาว
- `stories.js`: ฐานข้อมูลนิทานดวงดาวและตำนานดาราศาสตร์
- `server.js`: Node.js HTTP Server พร้อม Thai TTS Proxy
